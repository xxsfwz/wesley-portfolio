实习项目实践 / AI辅助实现

让多部短剧的混剪与解说制作，有一套可复用的处理流程。

要解决的问题

素材多、处理步骤重复；字幕、引用与草稿版本需要反复核对。

我的工作

拆解需求、设计流程，组织 Agent 与脚本执行，负责运行调试和人工验收。

实际应用

用于《Her Name Was Never His》《The Uncrowned King》等项目，历史记录包含单部30条混剪、10条解说的制作批次。

  1. 素材盘点与参数检查
  2. 抽帧、转写与剧情梳理
  3. 剪辑结构与可编辑草稿
  4. 字幕、素材引用和时间线复核
  5. 批量命名、分组与交付映射

重复的盘点、参数检查和文件整理交给工具；内容、节奏与异常结果保留人工判断。故障处理先备份、局部修复，再复验。
