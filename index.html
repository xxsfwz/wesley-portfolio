Case 01 / Content Tool

片前助手

我想解决的是“还没开剪，想法已经散了”的问题。

短视频前期整理工具

先把想法变清楚，再开始剪。

项目把主题、素材和发布平台整理成脚本骨架、分镜顺序、补拍提醒和封面标题。它不是一键成片，而是帮新手创作者把开剪前的清单准备好。

Role需求拆解 / 原型 / Demo ToolsHTML / CSS / JS / HyperFrames Time学生项目验证 Output项目页 / 原型 / Demo 视频
项目背景

很多短视频新手卡在开剪前，不知道脚本、镜头和素材缺口怎么整理。

难点

不能把功能说得太大，要先做一个能跑通流程的轻量版本。

结果

完成项目说明、可交互原型、Demo 视频和独立项目页。

Case 02 / Video Editing

Glide App 宣传片

项目类型：虚构 App 宣传片练习。重点是把抽象的信息流剪成清晰的画面节奏。

App Promo / Editing / Motion Package

把一天的信息流整理成行动路线。

我的职责包括脚本拆解、AI 镜头参考、PR 节奏剪辑和 AE 字幕包装。制作时最麻烦的是：信息很多，但画面不能乱。

Role剪辑 / 动效 / 视觉整理 ToolsPR / AE / PS / AI Time20 秒左右 Output概念宣传片
制作过程

先拆早晨、通勤、办公三个场景，再决定镜头顺序和字幕层级。

难点

把“信息流”这种抽象概念转成看得懂的节奏和画面重点。
