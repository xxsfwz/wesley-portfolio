# 片前助手 Demo 视频脚本

用途：给小满摘星计划笔试附加一个 25-30 秒 Demo 视频。风格要像学生项目验证，不要做成夸张商业广告。

## 成片定位

视频标题：片前助手：把想法整理成能开剪的清单

视频比例：16:9 或 9:16 都可以。优先 16:9，方便放进网站和项目页。

整体风格：干净、纸张感、轻产品 Demo。背景可以是浅米色、桌面、电脑屏幕、简单 UI 动效。不要赛博朋克，不要夸张科技蓝光。

## 旁白稿

很多新手做短视频，卡住的不是剪辑软件，而是开剪前不知道怎么整理。

比如一条校园咖啡店探店视频，素材拍了很多，但开头怎么说、镜头怎么排、还缺什么画面，经常要边剪边改。

片前助手先不做一键成片，它只做一件更小的事：把主题、素材和发布平台整理成脚本骨架、分镜顺序、补拍提醒、字幕层级和封面标题。

这样创作者打开剪辑软件之前，就已经有一张清楚的前期清单。

这个 MVP 先用规则模板跑通流程，后续再接入真正的 AI，根据用户反馈继续优化。

| 时间 | 画面 | 字幕 |
| --- | --- | --- |

| 3-7s | 素材、标题、脚本、分镜几个词乱成一团 | 是开剪前不知道怎么整理 |

| 18-23s | 结果依次突出：脚本骨架、分镜清单、补拍提醒、封面标题 | 脚本、分镜、补拍、封面 |
| 23-28s | 清单和剪辑时间线并排，画面变清楚 | 开剪前先把方向想清楚 |
| 28-30s | 项目名收尾 | 片前助手 / 内容 AI 早期项目 |
